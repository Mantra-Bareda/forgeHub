# Forge Hub V1.0 - Features
1. Local Multi-Model Routing: Easily switch between APIs for optimized querying.
2. Centralized Database: SQLite implementation for chats, settings, configuration, and API keys.
3. Profile Management: Editable user profile that dynamically injects Identity Memory (Name & Role) into the system prompt.
4. Intelligent Memory System: Context extraction that persists securely on-disk and integrates into system prompt dynamically.
5. Desktop Notifications & Status Tracking: Full system-tray and application event telemetry.
6. Theming Engine (Violet SaaS & Luxury Gold):
   - Dynamic PyQt6 theme engine powered by centralized Palette architecture.
   - Violet SaaS (Dark): Midnight canvas with Violet and Cyan glassmorphism.
   - Luxury Gold (Light): Obsidian background with Warm Ivory and Gold accents.
7. Seamless Packaging Prep: Fully portable application paths mapping to OS-specific AppData folders for production-ready distribution.
